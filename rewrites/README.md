# Copy-ready HK01 rewrites

Finished British-English Markdown lands in **`copy-ready/`**.

- Open `copy-ready/INDEX.md` for the list
- Open `copy-ready/LATEST.md` for the most recent rewrite
- Each article is also saved as `YYYY-MM-DD-<slug>-<id>.md`
- Raw Cantonese source notes land in **`inbox/<articleId>.json`** every 15 minutes via `python runner.py` (`HK01_RUN_MODE=inbox`)

House style: `.cursor/rules/markdown-style.mdc` (+ news-markdown-format / news-rewriting).
